# Codex 用量宠物

一个只读取本机 Codex 会话日志的 Windows 桌面小组件，不需要 API Key，也不会上传聊天内容。

## 显示内容

- 当前额度剩余百分比、额度周期和重置倒计时
- 当前运行项目名称、当前任务已消耗 Token，以及近两次刷新之间的消耗速度
- 按项目根目录聚合最近项目，通过 Codex 项目 ID 实时跟随项目改名；无项目映射时回退为工作目录名
- 项目列表按“项目创建以来全部累计 Token”从高到低排列，累计最多的位于最上方
- 每个项目同时显示本轮与今日累计 Token；点击“累计”可切换为项目创建以来的全部历史 Token
- 每个项目可独立隐藏；检测到同项目新的任务或会话后自动重新显示
- 单击项目行可直接跳转到对应的 Codex 任务
- 项目从工作状态转为完成/待命时发送 Windows 通知
- 独立的项目全生命周期用量排行，显示 Token 总量及占全部项目的比例
- 当前会话累计 Token（包含重复处理的输入、缓存输入与输出）
- 今天累计 Token
- Token 使用中文“万/亿”单位显示
- 今日输入、输出和缓存命中率
- 当前模型、工作/待命状态和低额度变色提醒
- “今日累计 / 今日输出 / 缓存命中”详情默认收起，可通过底部箭头随时展开
- 最近 14 天趋势图、最近 8 周用量柱状图
- 6 周每日用量热力日历
- 额度已使用 80% 和 90% 时分别通知（每个额度周期只提醒一次）
- 主窗口实时显示“数据正常 / 更新延迟 / Codex 未运行 / 数据异常”健康状态
- 控制中心可调整刷新间隔、排序方式、动画速度、窗口透明度、通知、置顶和开机启动
- 控制中心支持启动自动更新和手动“检查更新”
- 版本与自检页可检查日志、项目名称映射、Codex 跳转协议、累计缓存、动画资源及错误日志
- 工作时显示小猫快速挥爪敲键盘动画，待命时显示小猫趴下打盹和 `z/Z` 呼吸动画
- 双击小猫可切换“小猫模式”：隐藏全部详情并缩成只剩小猫，再次双击完整恢复；小猫外框、背景和窗口阴影均已移除
- 小猫模式四边和四角带有无边框、可接收鼠标的透明等比例缩放热区，可在 48～240 像素之间调整；缩放过程中小猫始终完整居中，尺寸单独保存且不影响完整窗口，并会自动留在当前屏幕可见范围内
- 小猫动画只切换动作帧，不再让整只小猫上下或左右位移

> “剩余额度”使用 Codex 日志中最近一次返回的 `rate_limits` 数据；它是服务端报告的额度窗口，不等同于 API 账户余额。

额度百分比按日志原始精度显示：日志返回整数时显示 `65%`，不会补成没有额外意义的 `65.00%`。

“会话（含缓存）”是当前 Codex 会话从创建以来累计处理的 Token。长会话会重复携带或读取上下文，缓存 Token 也包含在总量中，因此可能达到上亿；它不是单次上下文大小、剩余额度或直接费用。

## 安装

右键 `Install.ps1`，选择“使用 PowerShell 运行”。安装脚本会：

1. 在桌面创建“Codex 用量宠物”快捷方式；
2. 启动桌面宠物；
3. 不创建系统服务，也不会修改 Codex 配置。

如果需要开机启动，在 PowerShell 中运行：

```powershell
pwsh -ExecutionPolicy Bypass -File .\Install.ps1 -EnableAutoStart
```

## 使用

- 拖动卡片空白处：移动位置
- 双击小猫：隐藏全部详情并缩成只剩小猫；再次双击恢复原来的窗口尺寸和内容
- 小猫模式拖动四边或四角：等比例缩放小猫；拖动中间区域：移动小猫位置
- 像普通窗口一样拖动任意边缘或四角：宽度和高度可独立调整；内容自动重新排版，窗口较矮时项目列表在内部滚动；尺寸会自动保存
- 点击底部中央的宽箭头 `⌃/⌄`：单独收起或展开“今日累计 / 今日输出 / 缓存命中”区域；统计区固定跟随窗口底部，窗口高度也会同步缩短或向下恢复
- 点击右上角 —：最小化（双击托盘图标或桌面快捷方式恢复）
- 点击右上角 ×：隐藏到系统托盘
- 点击项目行右侧 ×：仅隐藏该项目监控行，不会停止 Codex 任务；新对话会自动恢复
- 单击项目行：在 Codex 桌面端打开该项目最近的任务
- 双击托盘图标：显示/隐藏
- 点击标题栏 `↺`：立即恢复全部隐藏项目
- 点击标题栏 `⚙`：打开控制中心设置页
- 托盘右键：打开用量历史、项目排行、设置、版本与自检，或刷新、显示所有隐藏项目（带数量）及退出
- 点击右上角 ▥ 或托盘“用量历史”：打开趋势与日历

重复双击桌面快捷方式不会再启动多个实例，而是自动唤醒已经运行或隐藏在托盘里的窗口。真正发生异常时，会弹出提示并把详情写入 `runtime-error.log`。

## 自动更新

桌面快捷方式现在先运行 `Start-CodexUsagePet.ps1`：检查助手自己的 GitHub `origin`，发现当前分支有可快进更新时先同步文件，再重启助手；没有更新时直接启动。控制中心可关闭启动检查，也可手动点击“检查更新”。检查结果记录在 `update.log`。

更新器只允许操作“项目目录本身就是 Git 仓库根目录”的仓库。如果目录嵌在其他项目仓库中，它会拒绝拉取，避免错误覆盖其他工程。要启用远程同步，需要把本目录建立为独立仓库，并连接专用 GitHub `origin`。

项目列表不限制项目数量。窗口能容纳多少就直接显示多少，其余项目用鼠标滚轮浏览；滚动条保持隐藏。全部项目都隐藏时，窗口自动缩成只保留标题控制栏和剩余额度的形态。

主窗口透明度可在控制中心设置为 40%–100%，保存后立即生效并记住选择；100% 保持原来的清晰外观。

额度区域保留额外的上下安全空间，避免在高 DPI 缩放下裁切百分比、进度条或重置时间。

“项目累计”按 Codex 项目的当前根目录归类，只改项目显示名不会把历史用量拆成两份。首次点击会建立 `.project-lifetime-cache.json`，以后直接读取缓存，并用正在运行的会话数据更新当前结果。

项目排行按创建以来的累计 Token 从高到低排列，并计算每个项目占所有已识别项目累计用量的比例。排行中的项目也可以单击跳转。

版本与自检位于控制中心第三页。绿色表示正常，黄色表示可选功能未启用或 Codex 当前未运行，红色表示需要处理的异常。

## 诊断

输出一次当前指标而不显示窗口：

```powershell
pwsh -ExecutionPolicy Bypass -File .\CodexUsagePet.ps1 -Once
```

## 数据说明

用量数据源为 `%USERPROFILE%\.codex\sessions` 下的本地 JSONL 日志，项目名称和项目 ID 映射来自 `%USERPROFILE%\.codex\.codex-global-state.json`。程序只解析时间戳、Token 汇总、任务状态、模型名称、项目元数据与额度字段；不会读取或显示用户消息和回答正文。

今日累计按照本地时区计算。跨午夜仍在运行的会话会以当天零点前的累计值作为基线。

首次打开历史页会扫描最近 60 天日志，可能需要十几秒；完成后会生成 `.usage-history-cache.json`，后续启动直接使用汇总缓存。缓存只保存日期和 Token 数字。

80%/90% 通知指“额度已使用比例”。同一个额度重置周期中，每档只提醒一次；检测到新的重置时间后会自动恢复提醒。

## 卸载

运行 `Uninstall.ps1` 会移除桌面快捷方式和开机启动项，不会删除项目目录或 Codex 日志。
